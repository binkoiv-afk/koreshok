# Читалка

Офлайн-читалка книг для Android: красивая по умолчанию, настраиваемая по запросу, без рекламы и трекинга.

## Что уже есть

- Библиотека из папок на устройстве: ищет книги во всех вложенных папках
- Метаданные и обложки из EPUB, FB2 и FB2.ZIP: автор, серия и номер, жанры, язык, год, аннотация
- Полка с поиском, сортировкой (название, автор, серия, год, дата добавления, последние открытые, прогресс) и группировкой (авторы, серии, жанры, языки, форматы, статус чтения)
- Русские названия жанров FB2, сортировка с учётом «ё»

## Дальше

1. Чтение EPUB и FB2: пагинация, темы, шрифты, оглавление, навигация
2. Закладки и выделения, экспорт в Markdown
3. OPDS-каталоги
4. PDF, DjVu, MOBI, CBZ, TXT и другие форматы
5. Синхронизация через WebDAV / Google Drive

## Сборка

APK собирается в GitHub Actions (вкладка Actions → последний запуск → артефакт `book-reader-apk`).

Локально: `./gradlew :app:assembleRelease` (нужен Android SDK). Модуль `core` с разбором форматов и логикой полки — чистый Kotlin, тесты: `./gradlew :core:test`.
