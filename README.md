# Корешок

Читалка книг для Android: красивая по умолчанию, настраиваемая по запросу, без рекламы и трекинга.

## Что уже есть

- Библиотека из папок на устройстве: ищет книги во всех вложенных папках
- Метаданные и обложки из EPUB, FB2 и FB2.ZIP: автор, серия и номер, жанры, язык, год, аннотация
- Полка с поиском, сортировкой (название, автор, серия, год, дата добавления, последние открытые, прогресс) и группировкой (авторы, серии, жанры, языки, форматы, статус чтения)
- Русские названия жанров FB2, сортировка с учётом «ё»
- Чтение EPUB, FB2 и FB2.ZIP: своя вёрстка страниц с переносами и выравниванием по ширине, абзац никогда не перестраивается при разрыве между страницами
- Четыре темы (день, сепия, ночь, чёрная), шрифт, размер, интервал, поля, красная строка
- Оглавление с вложенностью, ползунок по всей книге, сноски во всплывающем окне, «вернуться туда, где был» после перехода по ссылке
- Закладки касанием по уголку страницы, цитаты долгим нажатием на текст: 4 цвета, заметки, копирование, «поделиться»; список закладок и цитат книги с экспортом в Markdown
- Каталоги библиотек (OPDS): Флибуста и Project Gutenberg из коробки, свои каталоги по ссылке; поиск, листание, скачивание сразу в полку
- TXT: кодировка определяется сама (UTF-8, UTF-16, Windows-1251), главы находятся по строкам «Глава…», «Часть…»
- PDF и комиксы CBZ: лента страниц, масштаб двумя пальцами и двойным касанием, ползунок по страницам, закладки, ночной режим для PDF; первая страница становится обложкой на полке
- Обновления прямо из приложения: при запуске Корешок проверяет новую сборку на GitHub
- Место чтения и прогресс запоминаются; остальные форматы пока открываются во внешнем приложении

## Сборка

Свежий APK после каждого изменения: https://github.com/binkoiv-afk/koreshok/releases/latest/download/koreshok.apk

Локально: `./gradlew :app:assembleRelease` (нужен Android SDK). Модуль `core` с разбором форматов и логикой полки — чистый Kotlin, тесты: `./gradlew :core:test`.

## Подпись

Релизы подписаны постоянным ключом `app/signing/koreshok.jks`. Его создаёт CI при первой сборке после того, как владелец задаёт секрет `KEYSTORE_PASSWORD`; пароль знает только владелец. Без секрета сборка подписывается отладочным ключом, и такие версии нельзя поставить поверх друг друга.
